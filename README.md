# GENESIS AI

Интерактивная университетская выставка «Искусственный интеллект: генеративные технологии».

**Сайт:** https://artemshlyakov.github.io/generativeAI/

Пять страниц образуют маршрут **Главная → Технологии → Эксперименты → Медиа → Анкета**.

- `index.html` — сохранённый первый экран города будущего, единый блок о трёх технологиях и маршрут экспериментов.
- `technology.html` — научно-популярная статья: обучение, обработка запроса, изображения, видео, музыка, выбор инструментов и официальные источники.
- `experiment.html` — три основных опыта: день и ночь (ChatGPT Images), анимация кадра (Google Vids / Omni), песня (Suno). Сравнение ChatGPT и Gemini раскрывается внутри первого опыта. Здесь же сохранены события мыши для лабораторной №11.
- `gallery.html` — все пять исходных изображений, видео и музыкальная композиция; увеличение изображений с клавиатурной навигацией.
- `survey.html` — анкета с локальным итогом и сбросом. Данные не отправляются на сервер и не сохраняются после перезагрузки.

Сайт статический: HTML5, CSS, JavaScript. Сборка, API-ключи, базы данных и внешние библиотеки для работы не требуются. Шрифт Manrope с кириллицей хранится локально, лицензия SIL OFL — в `assets/fonts/`. Заголовки используют системную Georgia, сохраняя визуальную концепцию проекта.

## Запуск

Откройте `index.html` или запустите в корне репозитория:

```sh
python -m http.server 8765
```

Затем откройте http://localhost:8765/. Все пути относительные и совместимы с размещением GitHub Pages в `/generativeAI/`.

## Материалы и проверка

- `ASSET_MANIFEST.md` — происхождение файлов и оригинальные запросы. Версии моделей не приписываются там, где они неизвестны.
- `AUDIO_HANDOFF.md` — сведения о предоставленной композиции Suno.
- `LAB_COMPLIANCE.md` — реализация требований лабораторных №9–11 и известное отступление от XHTML 1.1.
- `LOCAL_QA.md` — актуальная проверка и её ограничения.
- `qa/verify.cjs` — повторяемая функциональная проверка в Chromium через Playwright. Требует установленного пакета `playwright` и Chromium; эта зависимость не нужна посетителям сайта. Команда: `node qa/verify.cjs http://localhost:8765/ /tmp/genesis-qa`.

Второе видео для сравнения пока не предоставлено; место для него предусмотрено внутри второго эксперимента. Три отчёта Word с полными листингами и свежими скриншотами подготовлены и переданы отдельно, в репозитории не хранятся. Реферат не входит в эту доработку. `AUDIT.md` и `GENERATION_BRIEF.md` отражают предыдущий этап работы, а не текущее состояние.

Минималистичные анимации используют нативные переходы страниц, Web Animations и CSS. Уменьшение движения учитывается при загрузке и при смене настройки. Основное содержимое всегда остаётся доступным. Дополнительная проверка: `node qa/motion.cjs` при запущенном локальном сервере на порту 8765.
