# GENESIS AI

Локальная цифровая выставка по теме «Искусственный интеллект: генеративные технологии». Пять HTML-страниц, общая таблица CSS, клиентский JavaScript, подлинные AI-изображения и настоящий AI-видеоклип. Откройте `index.html` в современном браузере. Если запуск `file://` ограничен, выполните `python -m http.server 8000` в папке сайта и откройте `http://localhost:8000/`. Интернет, пакеты и платные API для просмотра не нужны.

- `experiment.html` — слайдер дня и ночи, отдельный эксперимент с промптами и сравнение двух генераторов на одном запросе.
- `technology.html` — принципы, направления, критерии, таблица и список.
- `gallery.html` — компактная галерея с полноэкранным просмотром, локальное AI-видео с проигрывателем и паспортом, обозначенное место для AI-аудио.
- `survey.html` — локальная демонстрационная анкета, данные не отправляются.
- `ASSET_MANIFEST.md` — происхождение, даты и точные запросы.
- `GENERATION_BRIEF.md` — фактическая генерация Google Vids и проверки бесплатных аудио/видео инструментов.
- `AUDIO_HANDOFF.md` — порядок добавления композиции, когда она будет создана отдельно.
- `LAB_COMPLIANCE.md` — сверка задания №9–11 с фактической реализацией и указанным отступлением от XHTML 1.1.
- `LOCAL_QA.md` — выполненная браузерная проверка и инструкция по локальному запуску.

## Статус

Готовы настоящие изображения генерации и редактирования через ChatGPT Images. Второй кадр получен через Gemini Images. Из базового кадра Google Vids (Omni) создан и скачан 10-секундный MP4, который хранится локально. Сгенерированная музыка **пока не получена**; пользователь добавит её позднее по `AUDIO_HANDOFF.md`. Первая версия содержала SVG, монтаж статичных кадров и программный звук; эти материалы удалены. Отчёты в итоговом комплекте описывают текущую реализацию и не утверждают, что аудио готово. Пять страниц и адаптивность проверены в браузере через локальный HTTP-предпросмотр; способ `file://` не удалось проверить из-за ограничений браузерного окружения.

## Лабораторные

№9 — многосвязный сайт по теме реферата, изображения, таблица, список. №10 — единая внешняя `style.css`. №11 — JavaScript, изменение фоновой переменной документа, наведение на текст, три абзаца с эффектами, анкета с radio, select, несколькими текстовыми полями, множественным выбором и textarea. Использован HTML5 согласно решению об адаптации устаревшего типового задания XHTML.
