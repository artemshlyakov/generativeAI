# GENESIS AI

Учебная цифровая выставка по теме «Искусственный интеллект: генеративные технологии». Пять страниц образуют последовательный маршрут: **Выставка → Технологии → Эксперименты → Медиа → Анкета**. На каждой странице есть переходы к соседним главам и шкала всего маршрута.

Сайт работает без сборки, внешних библиотек и сетевых API. Откройте `index.html` в браузере. Если браузер ограничивает локальные файлы, запустите в папке проекта `python -m http.server 8000` и откройте `http://localhost:8000/`.

- `technology.html` — краткое объяснение принципов генерации, направлений и проверки результатов.
- `experiment.html` — сравнение дня и ночи, короткого и подробного запросов, результатов двух генераторов; демонстрация событий JavaScript.
- `gallery.html` — пять изображений с увеличением и локальный ролик image-to-video с паспортом.
- `survey.html` — демонстрационная анкета; введённые данные не отправляются на сервер.
- `style.css` и `script.js` — общие оформление и интерактивность.
- `ASSET_MANIFEST.md` — происхождение изображений и видео, точные запросы и наблюдения.
- `LAB_COMPLIANCE.md` — сверка с заданиями лабораторных №9–11.
- `LOCAL_QA.md` — результаты проверки в браузере.
- `reports/` — три отчёта Word с актуальными полными листингами.

Изображения и видео получены генеративными инструментами; точные версии моделей не приписываются там, где интерфейс их не сообщил. Готового AI-аудиофайла нет, поэтому аудиоэкспонат на сайте не заявлен. При необходимости план его добавления описан в `AUDIO_HANDOFF.md`.

Для лабораторной №11 использован современный HTML5 вместо указанного в методичке XHTML 1.1. Это отклонение прямо отражено в отчёте.
