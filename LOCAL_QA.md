# Проверка окончательной версии

Сайт не использует сборщик или внешние пакеты. Для локального запуска распакуйте архив и откройте `site/index.html` в современном браузере. Если браузер ограничивает доступ к локальным файлам, запустите из папки `site` команду `python -m http.server 8000` и откройте `http://localhost:8000/`. Интернет для просмотра экспонатов не нужен.

## Выполненная проверка

Окончательная версия просмотрена в Chrome через локальный HTTP-предпросмотр. На каждой из пяти страниц проверены ширины **320, 360, 390, 768, 1024, 1440 и 1920 пикселей**, а также разные высоты окна. Для проверенных состояний `scrollWidth` не превысил ширину окна; заголовки, кнопки, карточки и сравнение изображений не выходили за границы.

| Раздел | Проверенное действие |
| --- | --- |
| Навигация | Переходы между пятью страницами, выделение текущего пункта, мобильное меню, закрытие по Escape и возврат фокуса. |
| Эксперименты | Ползунок перемещён к обоим краям; дневное и ночное изображения и граница `--split` обновляются. Отдельно показаны сравнение промптов и двух моделей. |
| Медиа | Пять изображений загружены без ошибки. Лайтбокс открывается, листается, закрывается по Escape и возвращает фокус. Локальный MP4 воспроизводится, время ролика увеличивается. |
| Анкета | Заполнение тестовыми данными и отправка показывают локальный результат; сброс очищает его. Данные не отправляются на сервер. |
| Технологии | Таблица и материалы отображаются; на узком экране таблица прокручивается внутри блока. |

В консоли страницы не обнаружены ошибки приложения. Ошибки стороннего расширения браузера не относятся к сайту. Снимки финальной версии находятся в папке `screenshots` итогового архива и использованы в отчётах.

**Граница проверки:** браузерное окружение не разрешило навигацию по `file://`, поэтому прямое открытие двойным щелчком не подтверждено фактическим просмотром. Проверен эквивалентный локальный статический HTTP-запуск с относительными путями. Для полной проверки на своём компьютере откройте `site/index.html` двойным щелчком и повторите переходы, слайдер, лайтбокс, видео и анкету. Аудиофайл пока отсутствует и будет добавлен отдельно.
