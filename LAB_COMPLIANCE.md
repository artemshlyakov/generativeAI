# Сверка GENESIS AI с лабораторными №9–11

Источник: `ВвП_лр-9.pdf`, `ВвП_лр-10.pdf`, `ВвП_лр-11.pdf` (ВлГУ, кафедра ИСПИ). Проверено по разделам «Задание к работе» и «Содержание отчета».

| Работа | Требование методички | Реализация и проверка |
| --- | --- | --- |
| №9 | Сайт из нескольких страниц по теме реферата | `index.html`, `experiment.html`, `technology.html`, `gallery.html`, `survey.html` по теме «Искусственный интеллект: генеративные технологии». Относительные ссылки на всех страницах. |
| №9 | Отчет: цель, вариант, предметная область, структура, тексты HTML, выводы | В `Lab_09_GENESIS_AI.docx` приведены все указанные разделы и полные листинги пяти HTML-файлов. |
| №10 | Создать `style.css`, оформить сайт и подключить ко всем страницам, просмотреть в браузере | Один внешний файл `style.css` подключён ко всем пяти HTML. Дизайн-токены, адаптивные правила для 1100, 820, 600 и 420 px, состояния фокуса и уменьшение движения. Пять страниц просмотрены в браузере при 320, 360, 390, 768, 1024, 1440 и 1920 px. |
| №10 | Отчет: цель, вариант, предметная область, структура, текст CSS, выводы | В `Lab_10_GENESIS_AI.docx` включены разделы, актуальный полный CSS и скриншоты финальной версии. |
| №11 | Страница стандарта XHTML 1.1 | **Отступление от типового стандарта:** сайт написан на HTML5. Пользователь ранее указал общие указания курса, допускающие отход от типовых заданий при реализации технологий. Формального соответствия XHTML 1.1 нет; это прямо указать в отчете. |
| №11 | Скрипт задаёт фон документа и меняет его при наведении на текст | `script.js`: CSS-переменная `--page-bg` задается при `DOMContentLoaded`; `#ambient-trigger` меняет ее при `mouseenter`/`mouseleave` и `focus`/`blur`. |
| №11 | Три абзаца: цвет текста первого, фон второго, фон третьего только при наведении | `experiment.html` / `script.js`: первый и второй меняются при наведении с сохранением результата, третий восстанавливает фон при уходе указателя. |
| №11 | Анкета: radio, выпадающий список, несколько текстовых полей, email, телефон, множественный выбор, textarea; говорящие имена | `survey.html`: `preferredScene`, `favoriteMedium`, `visitorName`, `visitorEmail`, `visitorPhone`, `futureTopics`, `visitorComment`; `submit` выводит локальный результат, `reset` очищает его. |
| №11 | Предложения по динамике и основные события | Реализованы `DOMContentLoaded`, `mouseenter`, `mouseleave`, `focus`, `blur`, `input`, `submit`, `reset`, `click`, `keydown`; предложения и обоснование включены в отчет. |
| №11 | Отчет: цель, вариант, тексты JS, выводы | В `Lab_11_GENESIS_AI.docx` включены разделы, актуальный полный `script.js` и реальные снимки работы ползунка и анкеты. |

**Статус проверки:** все пять страниц просмотрены через локальный HTTP-предпросмотр, переходы и интерактивность проверены в браузере; MP4 воспроизводится, а скриншоты сделаны с финальной версии. На семи контрольных ширинах для каждой страницы горизонтальное переполнение и выход ключевых элементов за экран не обнаружены. Открытие `file://` в доступном браузерном окружении заблокировано политикой браузера, поэтому именно этот способ запуска не подтверждён; относительные пути не требуют сборки или внешних API. Аудио пользователь добавит отдельно, оно не требуется заданиями №9–11. См. `LOCAL_QA.md`.
